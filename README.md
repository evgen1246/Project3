# Система отслеживания самолетов с PostgreSQL ✈️

Программа собирает данные о самолетах в воздушном пространстве стран и сохраняет их в базу данных PostgreSQL.

## Функциональность

- Получение координат стран через Nominatim API
- Получение данных о самолетах через OpenSky Network API
- Сохранение данных в PostgreSQL
- Статистика по странам и самолетам
- Поиск самолетов по позывному
- Фильтрация по скорости

## Требования

- Python 3.8+
- PostgreSQL 12+
- Доступ в интернет

## Установка:

### 1. Установите PostgreSQL

Создайте базу данных и пользователя.

### 2. Клонируйте репозиторий

```
git clone <url>
cd airplanes_curse
```


3. Установите зависимости через Poetry

- Установка Poetry
```
pip install poetry
```

-  Установка зависимостей
```
poetry install
```

### 4. Настройте конфигурацию
Отредактируйте config.py:
```
DB_CONFIG = {
    'host': 'localhost',
    'port': 5432,
    'database': 'aircraft_tracker',
    'user': 'postgres',
    'password': 'your_password',
}

COUNTRIES = [
    'Russia',
    'United States',
    'Germany',
    'France',
]

```

### 5. Запустите программу
```
poetry run python -m src.main
```

### Использование и интерфейс:
```
1. Настроить базу данных (создать таблицы и загрузить данные)
2. Показать статистику
3. Показать все самолеты
4. Показать самолеты со скоростью выше средней
5. Поиск самолетов по позывному
6. Выход
```
При первом запуске выберите пункт 1 для создания таблиц и загрузки данных.
Затем используйте пункты 2-5 для просмотра статистики.

## Класс DBManager

Методы для работы с БД:
- get_countries_and_aeroplanes_count — страны и количество самолетов

- get_all_aeroplanes — все самолеты

- get_avg_speed — средняя скорость

- get_aeroplanes_with_higher_speed — самолеты выше средней скорости

- get_aeroplanes_with_keyword(keyword) — поиск по позывному
